## 功能

- **题库**：4 门课 × 300 题，基础 / 提高 / 进阶筛选，按知识板块练习
- **模考**：全真 100 题 / 60 分钟，快速 40 题 / 30 分钟，阶段闯关 50 题
- **标准卷**：每科 20 单选 + 5 多选，固定 100 题
- **抢答模式**：20 道单选，每题 15 秒
- **每日一练**：每天 10 题随机，早上 6 点换新；10 题全答才记打卡
- **题目目录**：方格显示对错，可跳题补做
- **背题模式 / 错题本 / 收藏 / 纠错标记 / 导出**
- **统计**：各科、各阶段掌握度，模考趋势
- **深色模式 / 字号调节 / 主攻科目 / 考点速查**
