## 本次更新（v2.1）

- 修复「每日一练」答完最后 10 题后点「查看结果」无反应：`finishSession` 调用了未定义的 `selEq`，异常中断导致结果页不渲染；已统一改用 `sameSet`。

- 「上一题」不再依赖当前题是否已答；最后一题还有未答题时，点「查看结果」会先提醒，可继续补做或仍然查看。

## 一、安装（安卓）

1. 把 `草学刷题_Android_v2.1.apk` 传到手机：微信文件传输助手、QQ、数据线均可。
2. 在手机上点开 APK，按提示安装。
3. 如果提示「未知来源 / 禁止安装」：
   - 小米 / Redmi：设置 → 应用设置 → 授权管理 → 安装未知应用 → 允许文件管理器/微信安装；
   - 华为 / 荣耀：设置 → 安全 → 更多安全设置 → 外部来源应用下载 → 允许；
   - 其他机型：在弹出提示中选「设置」→ 允许来自此来源。
4. 桌面出现绿色「草」字图标「草学刷题」，点开即用。

> 安装包使用安卓调试证书自签名，部分手机可能提示「未经安全检测 / 风险应用」，选择「继续安装」即可。App 不联网、不读取通讯录、不申请存储权限，学习记录只存在本机。

## 二、这一版有什么

### 1. 题库：每科 300 题，三阶段
- 每科：基础 150 + 提高 100 + 进阶 50 = 300 题。
- 题型：单选 190 + 多选 60 + 判断 50（贴合“单选 + 多选”赛制，判断题用于概念辨析）。
- 全部带解析；每题标课程、阶段、知识板块。
- 原有 100 题保留为「**大赛标准卷**」：每科正好 20 单选 + 5 多选，对应通知里要准备的那套题。

| 课程 | 总题 | 基础 | 提高 | 进阶 | 单选 | 多选 | 判断 | 标准卷 |
|---|---|---|---|---|---|---|---|---|
| 植物学 | 300 | 150 | 100 | 50 | 190 | 60 | 50 | 25 |
| 植物分类学 | 300 | 150 | 100 | 50 | 190 | 60 | 50 | 25 |
| 土壤学 | 300 | 150 | 100 | 50 | 190 | 60 | 50 | 25 |
| 普通生态学 | 300 | 150 | 100 | 50 | 190 | 60 | 50 | 25 |

### 2. 阶段口径
- **基础**：概念、结构、分类特征、术语，一步回忆即可作答。
- **提高**：应用判断、易混概念对比、简单情境分析。
- **进阶**：跨章节综合、计算题（孔隙度/容重/载畜量/能量传递/标记重捕/Jaccard/Shannon 等）、生产与生态情境。

### 3. 练习与考试
- **分阶段练习**：课程页点基础/提高/进阶，或按知识板块刷。
- **综合/随机/单选/多选/判断专项**。
- **背题模式**：直接显示答案与解析，快速过考点。
- **全真模考**：100 题 / 60 分钟，每科按基础 12 + 提高 8 + 进阶 5 抽题。
- **快速模考**：40 题 / 30 分钟，每科基础 5 + 提高 3 + 进阶 2。
- **标准卷**：固定 100 题 / 60 分钟（每科 20 单选 + 5 多选）。
- **阶段闯关卷**：基础/提高/进阶各 50 题 / 40 分钟。
- **抢答模式**：20 道单选，每题 15 秒，超时判错，模拟决赛抢答节奏。
- 模考带答题卡、倒计时、自动交卷、分项成绩。

### 4. 错题、收藏与纠错
- 答错自动进错题本；练习或模考中答对一次即自动移出。
- 收藏题、**纠错标记**（右上角 ⚑）分开管理。
- 可按课程 + 阶段筛选；可导出为文本，复制到群里核对。

### 5. 统计与设置
- 累计答题、总正确率、各科掌握度、**各阶段掌握度**。
- 最近模考正确率**趋势图**。
- **主攻科目**：对应四人分工，首页优先显示自己的科目。
- **深色模式**、三档字号。
- **考点速查卡**：四门课核心考点，考前速览。
- **每日一练**：每天 10 题随机抽题，按早上 6 点切换；10 题全部答完才记连续打卡天数。
- **题目目录**：练习/每日一练中点页脚「题目目录」，方格显示对错并跳题。

## 四、更新题库 / 重新打包

### 改标准卷（100 题）
编辑 `app/bank/*.json`，每科保持 20 单选 + 5 多选，然后：

```powershell
node app/build.js
```

### 改训练题库（1200 题）
训练题在 `gen/out/*.json`，按科目/阶段分批；每批的数量、题型、板块配额要与 `gen/specs/` 对应。完整构建会校验：

- 每科 300 题；基础 150 / 提高 100 / 进阶 50；
- 每科单选 190 / 多选 60 / 判断 50；
- 标准卷 25 题（20 单选 + 5 多选）；
- 题干不重复、选项不重复、答案下标合法、判断题选项为“正确/错误”。

```powershell
node app/build.js          # 完整校验
node app/build.js --partial  # 开发时允许题库未齐
```

### 重新出 APK
需要 JDK 17 与 Android SDK（platform 34 + build-tools 34.0.0）。脚本默认路径：

```
C:\Users\a2355\AndroidBuild\jdk\jdk-17.0.13+11
C:\Users\a2355\AndroidBuild\sdk
```

换机器时设置环境变量 `CAOYE_JDK`、`CAOYE_SDK`，或修改 `android/build.ps1` 顶部路径，然后：

```powershell
powershell -ExecutionPolicy Bypass -File android/build.ps1
```

产物：`android/build/caoye-quiz.apk`（versionCode 3 / versionName 2.1.0）。

## 六、说明

- 题目是依据大赛通知所列四门课程、教学大纲与高频考点编写的**模拟练习题**，不是大赛真题，也不代表官方评分口径；答案已做自动校验与分科审题，但仍建议队内负责人抽查后再用于定稿。
- 初赛笔试、决赛抢答，评分标准以现场公布为准；多选计分 App 采用“全部选对才计分”的保守口径。
- App 完全离线，学习记录只保存在本机；卸载 App 会同时清除记录。
- 网页版数据保存在浏览器 localStorage 中，换浏览器或清理缓存会丢失。
- APK 使用调试证书签名，队内安装够用；如需上架或长期分发，请用自己的发布证书重新签名。
